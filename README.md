# FocusPoint Camera Store

A responsive e-commerce homepage design for a camera store, featuring a mega menu, hero banner, product categories, featured products, SEO section, promo banner, and newsletter subscription.

## Files
- `index.html` — camera store homepage layout
- `styles.css` — modern dark theme styling with responsive layout
- `script.js` — newsletter subscription and contact button interaction

## Usage
1. Open `index.html` in a browser.
2. Customize product names, links, and images to match your store.
